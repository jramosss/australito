# Australito - Sistema Bimonetario de Gestión de Gastos

Proyecto informático universitario desarrollado en Java y MySQL.

## Descripción
El objetivo de este proyecto es proveer un sistema que resuelva la problemática de la economía bimonetaria argentina, permitiendo llevar un registro de gastos personales que automáticamente calcule la equivalencia en USD utilizando la cotización del Dólar Blue (vía DolarAPI).
